# Temporal alignment

A detailed guide to `ds.mx.align_time_with` and `mx.align_time`: each of
the four forecast/observation cases, worked examples of the `lead_time`
options (`"shortest"`, `"longest"`, specific lead times, and `"reference"` /
`"intersection"` / `"union"`), and the common `(reference_time, lead_time)`
grid built when several forecasts are aligned to observations.
