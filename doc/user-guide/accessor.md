# The `ds.mx` accessor

Importing `mxalign` adds an `mx` namespace to every `xr.Dataset`. This page
will cover all of it: the trait predicates (`is_grid`, `is_point`,
`is_forecast`, `is_observation`), the grid helpers (`add_crs`,
`add_grid_mapping`, `add_xy`, `stack`, `unstack`, `is_stacked`),
`add_valid_time`, and the two alignment entry points.
