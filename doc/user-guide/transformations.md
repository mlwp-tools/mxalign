# Transformations

Preparing variables so datasets are comparable: the built-in
transformations (`rename`, `kelvin_to_celcius`, `uv_to_speed`), calling any
external function through `external`, applying them to many datasets with
`mx.transform`, and registering your own with `register_transformation`.
